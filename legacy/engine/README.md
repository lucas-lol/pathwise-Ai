# PathWise AI：3D 沉浸式职业探索与自适应学习引擎

PathWise 是一个基于 3D 宇宙隐喻的职业能力图谱系统。它打破了传统的“填表式”职业测试，让探索者在 3D 星空中通过解决真实的职场危机来点亮技能树，并由底层的自适应算法动态生成个性化的成长路径。

## 🏗️ 核心架构设计

本项目采用**展示与计算分离**的架构思想，分为“交互展示层”与“核心算法引擎”：

1. **交互展示层 (前端/frontend-app)**
   - **技术栈**：React + Three.js + Framer Motion
   - **职责**：负责 3D 宇宙渲染、HUD 交互与叙事化体验。
   - **设计哲学**：为了保证极致的演示体验与零环境依赖，前端内置了一套轻量级的“本地规则引擎”。即使在完全离线的情况下（如直接访问 Vercel 部署链接），也能提供完整的 3D 探索闭环。

2. **核心算法引擎 (engine/)**
   - **技术栈**：FastAPI + SQLAlchemy + SQLite
   - **职责**：提供企业级的自适应学习算法服务。
   - **核心能力**：
     - **EMA 动态掌握度计算**：基于指数移动平均算法，结合题目难度动态更新用户的技能雷达图。
     - **防泄题抽题机制**：严格隔离题库数据，确保评估过程的严谨性。
     - **状态机流转引擎**：精确管理用户的“画像 -> 评估 -> 路线生成”全链路漏斗状态。
   - *注：在本地全栈开发环境中，前端可接入此引擎获取更深度的计算结果；线上演示环境默认使用前端本地引擎。*
